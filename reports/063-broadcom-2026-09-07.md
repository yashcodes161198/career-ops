Job Description:

Software Quality Assurance (QA) Engineer

We are seeking a detail-oriented Software Quality Assurance (QA) Engineer to drive software reliability, performance, and security across our multi-platform applications. In this role, you will partner closely with developers, product owners, and architects to embed quality into every stage of the Software Development Lifecycle (SDLC)—from sprint planning and acceptance criteria definition to automated CI/CD pipeline integration and environment deployments.​

Educational Qualifications:

- B.Tech/B.E./M.Tech/M.E. (Experience: 10+ years)

Key Responsibilities

- Develop, create, and maintain comprehensive test strategies, test plans, test cases, and test scripts for complex software applications.

- Develop, maintain, and expand automated test suites and integrate them into the CI/CD pipelines.

- Maintain test source code in git configuration control systems.

- Perform thorough manual, regression, and exploratory testing on new features and edge cases.

- Set up and maintain product deployments in various on-premise and cloud test environments and configurations.

- Identify, document, track, and triage software defects using tracking tools, ensuring clear steps to reproduce.

- Partner with developers and product owners to define acceptance criteria, review user stories, and ensure QA best practices are embedded in sprint planning.

- Drive improvement in software quality through design, code and test plan reviews.

Skills Required

- Proven experience with modern test automation tools.

- Hands-on experience using AI-assisted tools to accelerate writing test code, generating test scenarios, and debugging scripts.

- Solid experience testing RESTful APIs

- Familiarity with Git, issue-tracking software e.g. Rally, Jira, and CI/CD (e.g., Jenkins).

- Experience with Windows/macOS/Unix operating systems and cross-platform development and testing.

- Understanding of cloud platforms such as AWS, Azure, and GCP.

- Strong working knowledge of Agile/Scrum environments.

- Solid understanding of core security protocols and concepts and familiarity with web security standards.

- Knowledge of and experience with networking and communication protocols.

What makes you a strong fit
AI Expertise:

- You are an expert in using AI code assist tools (Claude/Cursor, etc.) as coworkers and not as prompt engineers.

- Good understanding of AI Spec-driven development methodologies like Plan/BMAD mode, etc., and use it thoroughly to map out and implement all phases of SDLC.

- Understand context engineering & token optimization techniques and create/maintain reusable skills and contexts across multiple teams and repos.

- Understand agent orchestration and manage multi-agent workflows to handle complex, multi-step engineering tasks like new capabilities, codebase refactoring, upgrades, and vulnerability patching.

- Code Review & Quality Control: Critically review AI-generated code for architectural alignment, design, and performance bottlenecks
