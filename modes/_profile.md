# Fresher candidate profile context

## Target roles

| Archetype | What to look for |
|---|---|
| Associate / Junior Software Engineer | Programming fundamentals, projects, coursework, 0-2 years experience |
| Graduate Engineer Trainee (GET) | Structured training programs, campus or off-campus hiring |
| Backend Engineer (Fresher) | APIs, databases, server-side projects, debugging |
| SDET / QA Engineer (Fresher) | API testing, automation, Pytest — secondary target |
| ML Engineer (Fresher) | Coursework, recommender projects — secondary only when CV supports it |

Frontend-only, mobile-only, and DevOps-only roles are optional, not primary.

## Evaluation policy

- Score against fresher and 0-2 year expectations, not senior-engineer expectations.
- Treat graduation window (2026) and campus eligibility as hard signals.
- Treat "3+ years required" or "5+ years required" as likely blockers.
- Do not penalize the candidate for lacking staff-level leadership or system ownership.
- Separate required qualifications from preferred qualifications.
- Prefer roles whose required skills have evidence in `cv.md`.
- Accept coursework, projects, internships, and certifications as evidence when explicit in the candidate's files.
- Never infer a technology, metric, user count, or impact from a project title.
